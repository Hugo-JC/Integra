# Integra Design System Engineering

1. Audit existing components and CSS variables before introducing tokens.
2. Define semantic roles first; map light/dark themes to shared roles.
3. Separate primitive values from semantic aliases; document ownership and allowed values.
4. Build type, spacing, radius, elevation and motion scales for the product's content and density.
5. Define component APIs and variants from real use cases.
6. Cover default, hover, active, focus, disabled, loading, error and selected states.
7. Set contrast, target-size, keyboard and reduced-motion constraints.
8. Provide usage and anti-usage examples plus migration notes.
9. Test token references and deprecated values.
10. Never enforce one theme across unrelated products.
