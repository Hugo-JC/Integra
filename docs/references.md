# Referências e proveniência

As decisões deste scaffold combinam a arquitetura discutida para o Integra e propostas de implementação ainda não verificadas em produção.

- Node.js — política e estado das releases: <https://nodejs.org/en/about/previous-releases>.
- WCAG 2.2 — referência de acessibilidade a usar na avaliação futura: <https://www.w3.org/TR/WCAG22/>.
- JSON Schema 2020-12 — formato dos contratos: <https://json-schema.org/draft/2020-12>.

Os repositórios `Hugo-JC/ai-design-engine`, `pbakaus/impeccable` e `morluto/rea` foram usados anteriormente como referências de conceitos, não como fontes de código copiadas para esta scaffold. A auditoria detalhada de licenças e de cada trecho deve preceder qualquer portabilidade.
