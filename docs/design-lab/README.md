# V5 Design Lab

O Design Lab é a suite de avaliação. Os cenários em `scenarios/` descrevem o que testar; as fixtures em `fixtures/` descrevem entradas e expectativas; os schemas em `schemas/` definem contratos; `src/lab/` contém helpers de cálculo usados pelos evaluators.

**Importante:** o runner completo ainda não existe. A validação atual verifica a qualidade da definição dos testes, não a qualidade de outputs gerados pelo motor.
