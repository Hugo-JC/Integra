# ADR-010: Evidence-first design investigation

- Status: Accepted
- Date: 2026-11-08

## Decision

Investigation records distinguish direct observations, official documentation, screenshots, source traces, inferences and unknowns. References are recorded with license and adaptation notes.

## Rationale

REA demonstrates the value of evidence-backed investigation and explicit limits. Integra applies that discipline to permitted UI/product analysis without importing unrelated binary-analysis capabilities.

## Consequences

- Findings cannot be promoted from inference to fact without new evidence.
- Screenshots support visible composition, not hidden behavior.
- References inform principles; they are not copied as code or assets.
- External adapters remain opt-in and must respect access and privacy boundaries.
