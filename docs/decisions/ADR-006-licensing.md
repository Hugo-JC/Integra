# ADR-006 — Licença do scaffold

- **Estado:** proposta aplicada ao scaffold; rever antes de publicar
- **Decisão:** o scaffold novo inclui uma licença MIT.

## Limites

Esta licença aplica-se apenas ao material incluído neste novo scaffold. Não concede direitos sobre os repositórios de terceiros usados como referência. Antes de portar código de `ai-design-engine`, `impeccable` ou `rea`, verificar a licença, o ficheiro de origem e as obrigações de atribuição de cada trecho. A estratégia de reutilização desses projetos continua dependente de uma auditoria específica.
