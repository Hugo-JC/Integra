# Anti-patterns to challenge, not blindly ban

- Default purple-to-blue gradients without a product reason.
- Same oversized centered hero on every landing page.
- Card-in-card nesting and repeated rounded rectangles.
- Decorative icon tiles above every heading.
- Low-contrast muted text and weak focus indicators.
- Arbitrary spacing, radius and shadows despite an existing scale.
- Charts without units, timeframe, source or table alternatives.
- Fake metrics, testimonials, logos, badges or product claims.
- Hover-only controls and inaccessible custom widgets.
- Motion without meaning or reduced-motion support.

A pattern is not a defect because it is popular. Evaluate purpose, context, execution, user impact and evidence.
