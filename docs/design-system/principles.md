# Integra design principles

1. Product intent before fashionable styling.
2. Content hierarchy before decoration.
3. A distinct visual thesis before generic component assembly.
4. Semantic tokens before one-off values.
5. Evidence-backed rules before universal taste rules.
6. Responsive behavior and interaction states are part of the design.
7. Accessibility is a quality constraint; automation supplements runtime and human review.
8. Preserve product identity unless a brief asks to change it.
9. Use references for principles, not copied layouts, assets, copy or brand identity.
10. A design system belongs to its product; Integra imposes no global theme.
