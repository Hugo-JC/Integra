# Brief — Interface para análise de genericidade visual

## Objetivo

Analisa a fixture `fixtures/source-projects/generic-interface/index.html` como se fosse a página inicial de um produto fictício de organização de projetos.

## O que procurar

- Hierarquia tipográfica insuficiente para distinguir título, conteúdo e ações.
- Repetição de elementos com aparência idêntica, apesar de funções diferentes.
- Ênfase visual pouco relacionada com o objetivo principal.
- Uso decorativo que compete com conteúdo importante.

## Cuidado com falsos positivos

Não classifiques dark mode, gradientes, cartões, cantos arredondados ou minimalismo como defeitos por si só. Só reporta um problema quando houver evidência e uma explicação ligada ao briefing.

## Saída esperada

Cada finding deve incluir categoria, gravidade, evidência reproduzível, impacto, recomendação e modo de verificar se a correção ajudou. Quando não houver evidência suficiente, assinala incerteza em vez de inventar problemas.
