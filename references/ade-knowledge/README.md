# Migrated AI Design Engine knowledge — historical archive

This folder preserves selected design knowledge migrated from `Hugo-JC/ai-design-engine`. It is useful as source-attributed research material, but it is **not the current runtime contract** and must not override current Integra documentation or code.

## Canonical current guidance

- `docs/ai-context-contract.md` — source precedence, facts/assumptions, evidence, findings and approval.
- `docs/ai-guides/preset-reference-escape-routing.md` — how to combine style routing, domain profiles, references and layout alternatives.
- `docs/design-quality-standard.md` — current quality criteria and task-led design rules.
- `presets/README.md` — the three current preset layers and their roles.
- `references/catalog.json` — current reference IDs used by the structured domain profiles.

## Archived contents

- `local-presets.json` — migrated legacy niche profiles, their original terms, variants, pattern cues and source provenance.
- `design-styles.json` — migrated legacy visual style tokens.
- `ai-design-rules.md` — historical rules retained for provenance; do not apply rigid numeric values without checking current standards.
- `curated-references.md` and `reference-sources.json` — historical source leads, not verification evidence.
- `layout-archetypes.md` — historical H/F/S/N/R structural pattern vocabulary; use as options, never as fixed templates.
- `component-catalog.md`, `design-intelligence-playbook.md`, `personality-extractor.md` and `reference-router.md` — archived reasoning material.

## Precedence and execution

1. Current user request and explicit deliverable.
2. Verified project behavior, existing identity and approved tokens.
3. Applicable accessibility, platform, legal and technical constraints.
4. Verified primary evidence relevant to the exact question.
5. Accepted Integra style route, structured profile and composition option.
6. Historical migrated hints and general design conventions.

Old commands such as `node tools/route.js`, `node tools/lint-repo.js` and `node tools/validate-design.js` belong to the source repository or a former layout. Do not assume they exist in Integra. Use the current commands documented in `presets/README.md`.

Historical colors, fonts, radii, accent percentages and layout ratios are not mandatory Integra tokens or proof of accessibility. A catalog URL or pattern cue does not mean the source was inspected. Preserve provenance, check current runtime behavior and verify source status before relying on a reference.
