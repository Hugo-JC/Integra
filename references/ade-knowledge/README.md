# Migrated AI Design Engine knowledge

This folder preserves the reusable design knowledge from Hugo-JC/ai-design-engine.

## Contents

- local-presets.json — original 61 niche profiles with matching terms, weak terms, legacy style IDs, variants, pattern cues, principles and source references. Each entry now has an advisory integra_preset_id mapping to the current preset catalog.
- design-styles.json — all 17 legacy visual style systems and their token guidance.
- ai-design-rules.md and anti-patterns.md — original rule corpus, retained as legacy reference.
- curated-references.md and reference-sources.json — original reference library and source metadata.
- layout-archetypes.md — layout pattern knowledge.
- component-catalog.md — component selection guidance.
- design-intelligence-playbook.md — original design reasoning playbook.
- personality-extractor.md — personality analysis guide.
- reference-router.md — original reference routing guide.

## Precedence

1. Explicit project brief and existing brand/design tokens.
2. Accessibility, platform, legal and technical constraints.
3. Integra current design quality standard and current contextual preset.
4. Legacy ADE mappings, style suggestions and reference material.

Legacy colors, fonts, radii or styles must not be applied without contextual review. They are neither mandatory Integra tokens nor proof of accessibility. Mapping from a legacy niche to an Integra preset is a starting hint and may need human review.
