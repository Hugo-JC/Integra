# Integra Core Principles

1. **Evidence before claims.** A finding needs evidence and a verification status.
2. **Context before styling rules.** Visual preferences are not universal defects.
3. **Separate generation from evaluation.** The generator cannot grade itself without independent checks.
4. **No silent success.** Missing tools and skipped checks must remain visible.
5. **Preserve user work.** Analyze copied projects first; write only inside an explicitly authorized workspace.
6. **Small, testable modules.** Modules communicate through documented contracts.
7. **Offline-capable core.** External investigation is an adapter, not a hard dependency.
8. **Accessibility is a quality constraint.** Automated checks complement manual review; they do not replace it.
9. **Version everything that affects results.** Schemas, scenarios, fixtures and baselines have explicit versions.
10. **Do not claim a test ran unless its execution evidence exists.**
